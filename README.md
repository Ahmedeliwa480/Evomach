# EvoMach

Smart Industrial IoT and Predictive Maintenance Platform.

## Overview

EvoMach is an industrial IoT platform for monitoring machinery, analyzing sensor data, and supporting predictive maintenance.

## Architecture
- Web: Next.js, React, TypeScript
- Mobile: Flutter, Dart
- Backend: Django, Django REST Framework
- ML Service: FastAPI, Python
- Database: PostgreSQL, TimescaleDB
- Cache and Tasks: Redis, Celery
- IoT: ESP32-S3, MQTT
- Infrastructure: Docker, Docker Compose
- Notifications: Firebase Cloud Messaging

## Repository
This repository follows a Monorepo architecture.
